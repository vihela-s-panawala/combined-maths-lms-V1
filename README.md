A simple paper class score analysis system for Advanced Level (A/L) Combined Mathematics students. 

### 🚀 Live Preview
Explore the live application here: **[combined-maths-lms-v1.vercel.app]**  
*(Note: This preview uses sample data. It is a simple frontend setup with no database connected and no signup/login required, ensuring total data privacy.)*


System is currently active in a practical environment (A class with 30-50 students).
This is just a preview project. Original project cannot be shared due to student data privacy.
A more robust version is currently in development. Future updates will include:

### 🛠️ Upgraded System (BETA)

* **Authentication:** Secure user signup and login system. With Google Authentication
* **Database Integration:** Persistent data storage for tracking scores over time.
* **AI Analyzing Engine:** Advanced insights and detailed performance metrics. Such as Future Focus Points and Current Weak pints absed on Per question Scores.
* **Question-Level Analytics:** Detailed breakdown per question to highlight specific areas needing future focus.
* **Expanded Scope:** Support for additional subjects, paper structures, and an integrated student feedback system.
* **An image-reading AI pipeline** to analyze submitted answer sheets, enabling per-question granular score tracking across Different paper Structures and Subjects such as MCQs Essays, etc.
